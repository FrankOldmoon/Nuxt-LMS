## ⏱️ 复杂度分析：1 秒的预算

竞赛的隐形考题：**你的算法跑得完吗？**

### 📊 大 O 速查

| 复杂度 | 1 秒内能处理 n 大约 |
| --- | --- |
| O(n) | 10⁸（1 亿） |
| O(n log n) | 10⁶ ~ 10⁷ |
| O(n²) | 10⁴ |
| O(2ⁿ)（搜索） | 20~25 |
| O(n³) | 500 |

### 🧮 估算示范

- n = 10⁵，O(n²) = 10¹⁰ → 必超时 ❌，需要 O(n log n)
- n = 3000，O(n³) = 2.7×10¹⁰ → 超时 ❌
- n = 10⁵，O(n log n) ≈ 10⁵ × 17 = 1.7×10⁶ → 稳 ✅

:::callout icon=💡
**拿到题先看数据范围**：n ≤ 20 → 搜索/状压；n ≤ 5000 → O(n²) DP；n ≤ 10⁵~10⁶ → O(n log n) 数据结构。数据范围就是出题人给你的提示！
:::

### ✍️ 函数

```cpp
long long sum(int n) {          // 返回值、参数、函数体
```

```cpp

//  & 表示引用：直接修改实参，还避免拷贝大对象
```

### 🔁 递归三要素

1. 🎯 **函数功能**：明确"这个函数算什么"
2. 🛑 **终止条件**：最小的问题直接给答案
3. 🔁 **递归调用**：把大问题变成更小的同类问题

```cpp
long long fact(int n) {
    if (n <= 1) return 1;       // 终止条件
    return n * fact(n - 1);     // 递归调用
}
```

:::callout icon=⚠️
递归深度太大会**爆栈（RE）**：n=10⁵ 的裸递归要改写成递推或显式栈。

## 🔍 枚举与模拟（难度 1–2）

### 🔍 枚举

把所有可能**逐一检查**。数据小的时候它就是正解：

```cpp
for (int i = 1; i <= n; i++)
    for (int j = i + 1; j <= n; j++)
```

先算枚举量：n² ≤ 10⁸ 才可行，否则要优化（枚举一半、剪枝、换思路）。

题目说啥就做啥，**忠实还原过程**。考察代码能力和细心程度：

- 📋 先用注释把流程列成步骤清单，再逐条翻译成代码
- 🧪 用题目样例手动 trace 一遍再提交

## 🔃 排序算法（难度 2–5）

### 🌱 入门级要求（1–3）

| 算法 | 复杂度 | 一句话 |
| --- | --- | --- |
| 冒泡排序 | O(n²) | 相邻交换，大的往后冒 |
| 选择排序 | O(n²) | 每轮选最小放前面 |
| 插入排序 | O(n²) | 像整理扑克牌，插入正确位置 |
| 计数排序 | O(n + k) | 值域小时按值计数 |

### 🌳 提高级要求（5）

- **归并排序** — 分治合并，O(n log n)，可求**逆序对**
- **快速排序** — 基准分区，平均 O(n log n)
- **堆排序** — 建堆后反复取堆顶
- **桶排序** — 按值域分桶再桶内排序

### 📊 稳定性

稳定排序保证相等元素相对次序不变：**冒泡、插入、归并、计数**稳定；**选择、快排、堆排**不稳定。

:::callout icon=💡
考场上直接 `sort()`（O(n log n)）；但要会手写归并（逆序对）和堆（面试/笔试常考）。
:::

## 🏃 贪心算法（难度 3）

**贪心**：每一步都做当前"看起来最优"的选择，寄希望于全局最优。

### ✅ 什么时候能贪？

- **贪心选择性质**：局部最优选择能导致全局最优
- 经典套路：**排序后贪**（按某关键字排好，再顺序处理）

### 📦 经典模型

- 🏦 区间调度：按**右端点**排序，能选就选 → 最多不重叠区间
- 🪙 找零钱：币值体系优雅时从大到小拿（注意：币值任意时贪心会错！）
- 🍉 合并果子：每次合并最小的两堆 → 用**小根堆**，哈夫曼树的雏形

:::callout icon=⚠️
贪心**不证明就敢用 = 赌博**。对策：① 交换论证（交换相邻两个选择不会更优）② 对拍/暴力验证小数据。CSP-S 第一题常是"贪心 + 排序"，正因如此。
:::

## 🔬 二分查找与二分答案（难度 3–4）

### 🔍 二分查找

**有序**才可二分。每次砍半，O(log n)：

```cpp
int lo = 0, hi = n - 1;
while (lo <= hi) {
    int mid = (lo + hi) / 2;      // 大数用 lo + (hi-lo)/2 防溢出
    if (check(mid)) hi = mid - 1;
    else lo = mid + 1;
}
```

STL 现成工具：`lower_bound`（第一个 ≥ x）、`upper_bound`（第一个 > x）。

### 🎯 二分答案

答案具有**单调性**时（"最多能…"），直接**二分答案本身**：

1. 确定答案区间 [lo, hi]
2. `check(mid)`：mid 的答案值是否可行
3. 可行则收缩，不可行则放宽

:::callout icon=💡
看到 "最小值最大 / 最大值最小"，先想**二分答案**。"跳石头"、"砍木头"都是模板题。
:::

## 📐 前缀和与差分（难度 3–4）

### 📐 前缀和 — 区间和 O(1) 查询

```cpp
S[0] = 0;
for (int i = 1; i <= n; i++) S[i] = S[i-1] + a[i];
// a[l..r] 的和 = S[r] - S[l-1]
```

二维前缀和同理（容斥原理）：`S[i][j] = a[i][j] + S[i-1][j] + S[i][j-1] - S[i-1][j-1]`。

### 📉 差分 — 区间修改 O(1)

对 a 的差分数组 d：`d[l] += x; d[r+1] -= x;` 一次完成整段加 x；最后前缀和还原。

:::callout icon=💡
黄金搭档：**前缀和管"静态查询"，差分管"批量修改"**。区间求和 → 前缀和；区间加减 → 差分；两者结合是入门级最高频考点之一。
:::

## 🌳 分治与倍增（难度 4–5）

### 🌳 分治

**分而治之**：拆分 → 解决子问题 → 合并。

- 归并排序、快速排序都是分治
- 经典应用：**归并排序求逆序对** —— 合并时统计右侧有多少元素已经越过左侧（CSP-S 常考）

### ⚡ 倍增

预处理 **2 的幂次** 信息，把线性跳跃变成 O(log n)：

- 从 f[i][k] = "从 i 跳 2ᵏ 步到哪" 出发，任意长度 = 二进制拆分
- 应用：ST 表（RMQ 区间最值）、LCA、快速幂

```cpp
// 快速幂：把 b 拆成二进制
long long qpow(long long a, long long b, long long mod) {
    long long res = 1;
    while (b) {
        if (b & 1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}
```

%%%%% S01
## 🌲 DFS 深度优先搜索与回溯（难度 3–4）

DFS：一条路走到底，走不通**回溯**换下一条。

### 🔁 回溯三步曲

```cpp
void dfs(int pos) {
    if (pos == n) { 记录答案; return; }   // 终止
    for (每个候选选择 c) {
        做出选择 c;                        // ① 进入
        dfs(pos + 1);
        撤销选择 c;                        // ② 回溯：恢复现场！
    }
}
```

经典应用：全排列、子集枚举、N 皇后、迷宫所有路径。

### ✂️ 剪枝

搜索的总状态数可能爆炸，剪枝是救命的：

- 🚧 **可行性剪枝**：当前已不合法，立即返回
- 📉 **最优性剪枝**：当前已劣于已知最优解，立即返回
- 🔢 **排序 + 上界**：先排好序，让剪枝更早触发

## 🌊 BFS 广度优先搜索（难度 3–4）

BFS 用**队列**逐层扩展 —— **第一次到达 = 最少步数**（无权图）。

```cpp
queue<PII> q;
q.push({sx, sy});  vis[sx][sy] = true;
while (!q.empty()) {
    auto [x, y] = q.front(); q.pop();
    for (int d = 0; d < 4; d++) {
        int nx = x + dx[d], ny = y + dy[d];
        if (合法 && !vis[nx][ny]) {
            dist[nx][ny] = dist[x][y] + 1;
            vis[nx][ny] = true;
            q.push({nx, ny});
        }
    }
}
```

### 🗺️ 应用清单

- 迷宫最短路（方向数组 dx/dy 四方向）
- **Flood Fill**（连通块计数/染色）
- 双端 BFS、多源 BFS（多个起点同时入队）

:::callout icon=⚠️
**vis 标记必须在入队时打**，不能出队时才打 —— 否则同一格会被重复入队，队列爆炸。
:::

## 🧮 动态规划入门：一维 DP（难度 4–5）

**DP 三部曲**：

1. 🧊 **状态设计**：`f[i]` 表示什么？（这是核心！）
2. 🔁 **状态转移**：`f[i]` 由哪些更小的状态推出？
3. 🏁 **初始化与答案**：边界值 + 最终在哪取答案

### 🪜 爬楼梯（入门模板）

```cpp
f[1] = 1; f[2] = 2;
for (int i = 3; i <= n; i++)
    f[i] = f[i-1] + f[i-2];   // 最后一步跨 1 阶或 2 阶
```

### 📈 最长上升子序列（LIS）

`f[i]` = 以 i 结尾的最长上升子序列长度：

```cpp
for (int i = 1; i <= n; i++) {
    f[i] = 1;
    for (int j = 1; j < i; j++)
        if (a[j] < a[i]) f[i] = max(f[i], f[j] + 1);
}
// O(n²)；提高级可用"单调栈+二分"做到 O(n log n)
```

:::callout icon=💡
DP 与递归的关系：**记忆化搜索 = 递归 + 缓存 = 自顶向下 DP**。会搜就会 DP，重点是状态设计。
:::

## 🎒 背包 DP（难度 5）

### 🎒 01 背包 — 每件物品最多选一次

```cpp
for (int i = 1; i <= n; i++)
    for (int j = m; j >= w[i]; j--)      // 逆序！
        f[j] = max(f[j], f[j - w[i]] + v[i]);
```

⚠️ **01 背包必须逆序**（保证每件只选一次）；求方案数/最值同理。

### ♾️ 完全背包 — 每件无限选

```cpp
for (int i = 1; i <= n; i++)
    for (int j = w[i]; j <= m; j++)      // 正序！
        f[j] = max(f[j], f[j - w[i]] + v[i]);
```

### 🔢 多重背包 — 每件有限件数

朴素三重循环，或**二进制拆分**优化成 01 背包（把 s 件拆成 1,2,4,… 件打包）。

:::callout icon=💡
背包问题万变不离其宗：**「容量是状态、物品是阶段、选/不选是转移」**。数硬币凑钱、装箱、时间分配全是背包换皮。
:::

## 🌲 区间 DP、树形 DP 与状压 DP（提高级，难度 6–7）

### 📏 区间 DP — 按长度枚举

`f[i][j]` = 区间 [i, j] 的最优值，**从小到大枚举区间长度**：

```cpp
for (int len = 2; len <= n; len++)
    for (int i = 1; i + len - 1 <= n; i++) {
        int j = i + len - 1;
        f[i][j] = min over k of (f[i][k] + f[k+1][j] + cost);
    }
```

经典：石子合并、能量项链。

### 🌳 树形 DP — 后序遍历

在树上做 DP：**先算完所有子树，再更新父节点**（没有依赖反转）。

经典：没有上司的舞会（选/不选相邻约束）、树的直径。

### 🎴 状压 DP — 用二进制表示集合

n ≤ 20 时，把"选了哪些"压成一个二进制数 `S`：

```cpp
for (int S = 0; S < (1 << n); S++)
    for (int i = 0; i < n; i++)
        if (!(S >> i & 1))   // i 不在集合中
            f[S | (1 << i)] = min(f[S | (1 << i)], f[S] + w);
```

经典：旅行商（TSP）、棋盘覆盖。

## 🧱 线性结构：栈、队列、链表、单调队列（难度 2–5）

### 🌱 基础（手写或 STL）

- 🥞 **栈**（LIFO）：括号匹配、表达式求值、DFS
- 🚶 **队列**（FIFO）：BFS、任务排队
- 🔗 **链表**：O(1) 插入删除（竞赛常用数组模拟：`nxt[i]` 存下一节点）

### 🌳 单调队列（难度 5）

**滑动窗口最大/最小值**的 O(n) 解法：

```cpp
deque<int> dq;                       // 存下标，值单调递减
for (int i = 0; i < n; i++) {
    while (!dq.empty() && a[dq.back()] <= a[i]) dq.pop_back();
    dq.push_back(i);
    if (dq.front() <= i - k) dq.pop_front();     // 出窗
    if (i >= k - 1) cout << a[dq.front()];       // 窗口最大值
}
```

队列里的下标对应值**单调**，队头永远是当前窗口的最值。应用：DP 优化、多重背包。

## 🌿 并查集（难度 4–5）

**并查集**管理"元素分组"：快速回答「a 和 b 在同一集合吗？」并支持合并。

```cpp
int fa[N];
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }  // 路径压缩
void merge(int a, int b) { fa[find(a)] = find(b); }
```

- 🔍 **find**：一路找祖先；**路径压缩**让链变短，几乎 O(1)
- ⚖️ **按秩合并**：小树挂大树，双保险
- 🧮 初始化：`fa[i] = i`，连通块个数 = 根的个数

### 📦 经典应用

- 🔗 动态连通性（朋友圈、亲戚）
- 🌲 **Kruskal 求最小生成树**
- 🍽️ 关系/性别并查集（带权并查集，提高级）

## ⛰️ 堆与哈夫曼树（难度 4–5）

### ⛰️ 二叉堆

**完全二叉树**，父节点 ≤（小根堆）或 ≥（大根堆）子节点：

- 插入/删除 O(log n)，取最值 O(1)
- STL：`priority_queue`（默认大根堆，`greater<int>` 变小根堆）
- 手写：`up` / `down` 调整

经典应用：合并果子（每次取最小两堆）、Dijkstra 优化、第 K 大元素。

### 🎋 哈夫曼树

**带权路径长度（WPL）最小**的二叉树：权值越大的叶子离根越近。

构造：贪心 —— 每次取最小的两个合并，用**小根堆**维护。应用：哈夫曼编码（高频字符编码短，压缩的鼻祖）。

## 🌲 树状数组与线段树（提高级，难度 6–7）

两大数据结构解决同一类问题：**单点/区间修改 + 区间查询**。

### 🌲 树状数组（Fenwick Tree）

代码短、常数小，管**前缀和类**信息：

```cpp
int lowbit(int x) { return x & (-x); }
void update(int x, int v) { for (; x <= n; x += lowbit(x)) c[x] += v; }
long long query(int x) { long long s = 0; for (; x; x -= lowbit(x)) s += c[x]; return s; }
// 区间和 = query(r) - query(l-1)
```

核心是 `lowbit`：x 二进制最低位的 1，决定节点的管辖范围。

### 🌳 线段树

全能选手：区间最值、区间和、区间染色 + **懒标记（lazy tag）** 批量更新。

```cpp
// 结构：每个节点管一段 [l, r]，左右儿子各管一半
// 查询/修改都是 O(log n)；代码量大，考场上背模板
```

:::callout icon=💡
选型：只查前缀和/单点改 → 树状数组（30 行）；要区间最值/区间赋值 → 线段树（80 行）。

## 📝 字符串算法：KMP、哈希与 Trie（提高级，难度 6–7）

### 📝 KMP — O(n+m) 模式匹配

`next` 数组 = 模式串每个前缀的「最长相等前后缀」长度；匹配失败时模式串**跳到 next 位置**继续，主串指针从不回退。

### 🧂 字符串哈希

把字符串看成进制数取模，**O(1) 判断任意两个子串是否相等**：

```cpp
h[i] = h[i-1] * base + s[i];        // 预处理
get(l, r) = h[r] - h[l-1] * pw[r-l+1];  // 子串哈希值
```

⚠️ 用大质数取模，双哈希防碰撞。

### 🌲 Trie 字典树

按字符逐层建树：查询单词/前缀 O(串长)。应用：单词统计、异或前缀（01-Trie）。

## 🗺️ 图的存储、遍历与拓扑排序（难度 3–5）

### 🗺️ 两种存储

```cpp
// 邻接矩阵：O(n²) 空间，适合稠密图
int g[N][N];

for (auto [v, w] : g[u]) { ... }
```

- ✅ DP 顺序：DAG 上的 DP 按**拓扑序**转移（如“食物链”“最长路”）

## 🛣️ 最短路：Dijkstra、SPFA 与 Floyd（难度 5–7）

| 算法 | 适用 | 复杂度 | 备注 |
| --- | --- | --- | --- |
| **Dijkstra** | 无负权边 | O(m log n)（堆优化） | 单源首选 ✅ |
| **SPFA** | 可负权 | 平均快，最坏 O(nm) | 判负环 |
| **Floyd** | 任意 | O(n³) | 多源、代码 5 行 |

### 🛣️ Dijkstra（堆优化）

```cpp
priority_queue<PII, vector<PII>, greater<PII>> q;  // {dist, node}
q.push({0, s});
while (!q.empty()) {
    auto [d, u] = q.top(); q.pop();
    if (vis[u]) continue;  vis[u] = true;
    for (auto [v, w] : g[u])
        if (d + w < dist[v]) { dist[v] = d + w; q.push({dist[v], v}); }
}
```

⚠️ **Dijkstra 不能处理负权边** —— 贪心"已确定的点不会再变"会失效。

### 🧮 Floyd（多源）

`g[i][j] = min(g[i][j], g[i][k] + g[k][j])`，三重循环跑一遍，全源最短路直接到手。

## 🌉 最小生成树与二分图（难度 5–6）

### 🌉 最小生成树（MST）— n 个点 n−1 条边的最小连通方案

- **Kruskal**：边按权排序 → 并查集判连通 → 依次加入不构成环的边。O(m log m)，写法简单首选 ✅
- **Prim**：从点出发，每次加"离树最近的点"，堆优化 O(m log n)，适合稠密图

### 🎨 二分图

顶点能分成两组、所有边跨组的图。判定：**染色法**（BFS/DFS 交替染两色，冲突则不是）。

- 📐 经典结论：**二分图不存在奇环**
- 💍 匹配问题（匈牙利算法，难度 7）：如"学生选课""任务分配"

:::callout icon=💡
图论题的建模思路：把实际问题翻译成「点 = 什么，边 = 什么，问的是最短路/MST/拓扑中的哪个模型」—— 模型对了，剩下的都是模板。
:::

### 🔢 进制转换（笔试必考）

```cpp
// 十进制 → 二进制：除 2 取余，倒着读
// 2^k 权重：512 256 128 64 32 16 8 4 2 1
// 例：1011₂ = 8+2+1 = 11
```

### ⚡ 位运算速查

| 运算 | 含义 | 竞赛用途 |
| --- | --- | --- |
| `x & 1` | 末位 | 判奇偶（1=奇） |
| `x >> k` | 右移 | x / 2ᵏ |
| `x << k` | 左移 | x × 2ᵏ |
| `x & (x-1)` | 去掉最低位的 1 | 统计二进制 1 的个数 |
| `x & (-x)` | lowbit | 树状数组 |
| `^`（异或） | 不同为 1 | 成对消去、找单身狗 |

## 🧭 质数、GCD 与快速幂（难度 4–5）

### 🧭 质数与筛法

- 试除法判质数：只试到 √n，O(√n)
- **埃氏筛**：O(n log log n) 打出 [1, n] 全部质数表

```cpp
for (int i = 2; i * i <= n; i++)
    if (!comp[i]) for (int j = i * i; j <= n; j += i) comp[j] = true;
```

### ⚖️ GCD 与 LCM

**辗转相除**：`gcd(a, b) = gcd(b, a % b)`，O(log)。

- `lcm(a, b) = a / gcd(a, b) * b`（先除后乘防溢出！）
- **扩展欧几里得**：求 ax + by = gcd(a,b) 的解 → 乘法逆元（提高级）

### ⚡ 快速幂

aᵇ 按二进制拆分，O(log b) 完成取模幂（见"分治与倍增"章代码）。**数论几乎全部建立在取模 + 快速幂上**。

## 🎲 组合数学与高精度（难度 4–6）

### 🎲 计数原理

- ➕ 加法原理（分类）：各类方案数相加
- ✖️ 乘法原理（分步）：各步方案数相乘
- 🎴 排列 A(n,k) = n!/(n−k)!，组合 C(n,k) = n!/(k!(n−k)!)
- **杨辉三角递推**：C(n,k) = C(n−1,k−1) + C(n−1,k) —— 取模计数题的标配

### 🚫 容斥原理

"至少满足一个" = 单个之和 − 两两之交 + 三三之交 − …（奇加偶减）

### 🔢 高精度运算（难度 4）

C++ 的 int/long long 不够时（>10¹⁸），用**数组按位存储**模拟竖式：

- 存储：`vector<int>` 每位一个数字，低位在前
- 加/减：逐位运算 + 进位借位
- 乘法：逐位相乘再错位相加
- 提高级：压 9 位、FFT 乘法（难度 8+）
